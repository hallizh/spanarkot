# Spánarkot ☀️

Dagskipulag fyrir síðustu dagana í Torrevieja (Los Dolses, Orihuela Costa) fram að heimferð **2. júlí 2026**.

Fyrir hvern dag sést:

- 🌤️ Veðurspá — hiti dags og nætur, veðurlýsing
- ☀️ UV-stuðull með ráðleggingum um sólarvörn
- 🌡️ Sjávarhiti
- 🌊 Sjólag — ölduhæð með mati fyrir börnin (sléttur sjór → stórar öldur)
- 💨 Vindur og ☔ úrkomulíkur
- 💡 Tillaga dagsins — strandir, matur, dagsferðir og rólegheit, valið eftir veðri og vikudegi (markaðsdagar á réttum dögum!)

## Að keyra

Þetta er hrein statísk vefsíða — ekkert að setja upp, engir API-lyklar.

**Beint:** opnaðu `index.html` í vafra.

**GitHub Pages:** Settings → Pages → Deploy from branch → veldu branchinn og `/ (root)`. Síðan birtist á `https://<notandi>.github.io/spanarkot/`.

Veðurgögn koma í rauntíma frá [Open-Meteo](https://open-meteo.com/) (ókeypis, enginn lykill). Spáin nær 16 daga fram í tímann — dagar lengra í burtu sýna dæmigert veður fyrir árstímann þar til spáin nær til þeirra.
